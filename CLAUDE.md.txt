#My Project

It needs to take charts from API ( maybe tradingView), apply an algorithm and say if it should be longed or shorted, with stoplosses/targets. Initially i just want the structure, we will worry about the algorithms later.
This will be just backend.

##Stack

Can add frameworks to make things easier.

	the master service, i want 2 versions. One that reads from a list of charts to read and sequentially, calls the api and applies the algorithm .
